# Privacy

Windows Debloater does its work on your PC. It asks the internet one question: is there a newer version?

- **The update check.** When the tool opens, at most once a day, it fetches one small file from this project's latest release on GitHub (`github.com/Coursion-Studio/windows-debloater/releases/latest/download/update.json`), which says what the newest version is. The request carries nothing about you or your PC except what every web request carries, your IP address, and the name and version of the tool (for example `WindowsDebloater-Windows/0.4.0`). GitHub's handling of it is covered by GitHub's own privacy statement. You can switch the check off on the Settings page ("Check for updates when the tool opens"), and then nothing is asked until you press "Check for updates now" yourself. A dry run and demo mode never ask.
- **Updating.** If you press "Update now", the new installer is downloaded from this project's releases on GitHub and run only if two things hold: its SHA-256 matches the one in that file, and it carries a signature made with Coursion Studio's update key, which the tool checks with the public half it ships with. Nothing is downloaded unless you press that button, and nothing from anywhere else is accepted.
- **No analytics, no telemetry, no account.**
- **What it stores.** Your language, theme, the size of the window, what you last ticked, whether to check for updates and when it last did are saved in `%LOCALAPPDATA%\WindowsDebloater\settings.json`. Selections you saved under a name are in `selections.json` next to it, and so is a note of a newer version that was found, in `update.json`. Each run writes a folder under `%LOCALAPPDATA%\WindowsDebloater\runs` containing the list of changes you chose, a log of what happened, the previous value of every setting it changed and the names of the apps it removed, so that the run can be reverted. These files stay on your PC. Delete the folder whenever you like; you only lose the ability to revert those runs from the History page.
- **Selection files.** A selection you save as a file, to use on another PC, holds the name you gave it, the day, the version of the tool and the list of changes. It names neither you nor your PC, and it goes only where you put it. A selection file you open is read as a list of changes and nothing else.
- **What it reads.** The list of installed apps, the registry values named in [docs/changes.md](docs/changes.md), and, if you choose to remove OneDrive, the files in your OneDrive folder so it can copy them. None of it leaves the PC.
- **The things that open something else.** "Open in Store" on the History page opens the Microsoft Store app on that app's page. "Project page on GitHub" on the Settings page and "What's new" on the update sheet open this project's page in your browser. On the same page, "coursion.studio" opens the website and the support address opens your mail program with a new message; "Licence" only opens the licence file that came with the tool, the MIT licence. All of them happen only when you click them. What the Store and GitHub do is covered by their own privacy policies, not this one.
- **The installer.** It copies the program into `%LOCALAPPDATA%\Programs\WindowsDebloater`, adds a Start menu shortcut and an entry under Settings > Apps > Installed apps, all within your own user account. It contacts nothing.
